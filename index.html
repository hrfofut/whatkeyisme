Set up

Two keys and you're in. Both stay on this computer (saved to config.json next to server.py).

  1. Open the Spotify Developer Dashboard → Create app (or open your existing one). Tick Web API and add this Redirect URI:
    http://127.0.0.1:5000/callback
  2. Copy the app's Client ID (no secret needed — this uses PKCE).
  3. Get a free GetSongBPM API key for key/BPM lookups (Spotify no longer gives new apps this data).
Preview demo

See the key of whatever you're playing on Spotify

whatkeyisme shows your current Spotify track with a full play bar and its key signature: sharps and flats, Camelot code, BPM, the scale on a piano, and keys that mix well with it. Key and BPM data come from GetSongBPM.

It runs on your own computer: download it from GitHub, run python server.py, and open http://127.0.0.1:5000.
